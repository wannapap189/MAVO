# MAVO — ต้นแบบดีไซน์ล่าสุด

หน้าเดียวที่เริ่มจากความประหยัด → เลือกรุ่นเครื่องพิมพ์ → ตรวจคุณภาพ → MAVO Care Online → บทความและ LINE

## เปิดดูทันที

ใช้ Node.js 24 ขึ้นไป จากราก repository:

```sh
node design-preview/server.mjs
```

เปิด http://127.0.0.1:12502/ หากพอร์ตถูกใช้อยู่ ให้กำหนด `MAVO_DESIGN_PORT` เป็นพอร์ตอื่น ไม่ต้องติดตั้งแพ็กเกจเพื่อเปิดไฟล์ preview ที่แนบมา

## แก้ไขและสร้างใหม่

```sh
cd design-preview
npm install
npm run build
npm start
```

- `src/components/MAVOWebsitePrinterFinder.tsx` — หน้าและการโต้ตอบ
- `src/components/MAVOWebsitePrinterFinder.css` — ดีไซน์ responsive
- `src/components/data.ts` — snapshot ข้อมูลสาธารณะ 92 สินค้า / 207 รุ่นเครื่อง ณ 26 พ.ย. 2569
- `public/` — รูป ฟอนต์ PDF และ llms สำหรับ preview
- `preview/` — ไฟล์พร้อมเปิด เป็น public root เฉพาะต้นแบบนี้

`src/scaffold.css` เก็บ reset/theme ที่ใช้ในต้นแบบที่ตรวจแล้ว ส่วน component CSS เป็นเจ้าของสไตล์ MAVO เมื่อนำเข้าระบบ frontend อื่นให้ตรวจผลร่วมกับ CSS ของระบบนั้น

## ขอบเขตข้อมูลและการเชื่อมระบบ

ราคา MAVO แสดงรวม VAT และส่งปกติในประเทศ ราคาอ้างอิงต้องแยก SRP, ราคาแค็ตตาล็อก และราคาขายเว็บแบรนด์ตามหลักฐาน ไม่ตีความการเทียบราคาต่อตลับว่าได้จำนวนหน้าหรือคุณภาพเท่ากัน

ข้อมูลในต้นแบบยังไม่ซิงก์กับ `dist/data/products.json` อัตโนมัติ ก่อนปรับราคาให้อัปเดตทั้ง snapshot และแหล่งข้อมูลเว็บหลัก พร้อมทดสอบส่วนต่างราคาใหม่

ต้นแบบนี้มีการค้นหารุ่นและคำนวณราคาใน browser ปุ่ม LINE เปิดช่องทางติดต่อจริง บทความเปิดอ่านได้ ไม่มีระบบรับคำสั่งซื้อ ลงทะเบียน Serial หรือสร้างเคสเคลมอัตโนมัติในต้นแบบนี้

รับประกัน 1 ปีตามเงื่อนไข พร้อม MAVO Care Online ไม่มีบริการเดินทางไปเปลี่ยนตลับถึงที่ ใช้โลโก้เดิม สีน้ำเงินเข้ม #09253d ฟ้า #5cc6e7 และปุ่มส้ม #ff8a1f

ต้นแบบมาจาก MagicPath revision `476589219498831872` แต่ React source ในโฟลเดอร์นี้ใช้ asset ในเครื่อง เปิดดูได้โดยไม่ต้องมีบัญชี MagicPath ยังไม่ได้แทนเว็บหลักใน `dist/` และยังไม่มีการเปิดเว็บไซต์สาธารณะ

ฟอนต์ Noto Sans Thai ใช้ SIL Open Font License ดู `public/assets/OFL.txt` โลโก้และภาพ MAVO ใช้สำหรับโครงการ MAVO ไม่ได้ประกาศอนุญาตให้บุคคลอื่นนำแบรนด์ไปใช้
