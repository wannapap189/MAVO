MAVO — การตั้งค่าโดเมนภายหลัง

สถานะปัจจุบัน
เว็บไซต์ยังเป็นตัวอย่างในเครื่อง ไม่ได้เผยแพร่ ไม่มีโดเมนสาธารณะ และยังไม่ส่ง URL ให้ Google
site.config.json ตั้ง origin เป็นค่าว่าง และ indexable เป็น false
หน้าบทความมีเนื้อหา รูปภาพ และลิงก์ใน HTML พร้อมอ่านโดยไม่ต้องรอ JavaScript

เมื่อมีโดเมนจริงและพร้อมเผยแพร่
1. เปิด site.config.json
2. ใส่ origin เป็น URL HTTPS หลักของเว็บไซต์จริง โดยไม่มีชื่อหน้า พารามิเตอร์ หรือโฟลเดอร์ท้าย URL
3. เปลี่ยน indexable เป็น true เมื่อพร้อมให้เครื่องมือค้นหาเข้าถึง
4. รัน node build.mjs จากโฟลเดอร์ mavo-website
5. ตรวจเว็บไซต์ที่สร้างใหม่ใน dist ก่อนนำขึ้นโฮสต์

ระบบสร้างจากค่าจุดเดียว
- Canonical URL และ URL รูปภาพสำหรับแชร์บทความ
- Open Graph และข้อมูล Article/Breadcrumb ของบทความ
- sitemap.xml และ robots.txt สำหรับโดเมนจริง
- ปุ่มแชร์ลิงก์บทความจะพร้อมเมื่อมี URL สาธารณะ ส่วนคัดลอกข้อความและดาวน์โหลดเช็กลิสต์ใช้ได้ในเครื่อง

ก่อนเปิดเว็บจริง
ใส่ช่องทางติดต่อที่เปิดใช้งานแล้ว และตรวจราคา/เงื่อนไขบริการให้ตรงกับการขายจริง
ตรวจ HTTPS, ลิงก์หน้าและภาพ, หน้าบนมือถือ และ URL หลักที่โฮสต์ใช้งาน
การ build ไม่ใช่การเผยแพร่หรือการรับประกันอันดับค้นหา การเชื่อม Search Console และส่ง sitemap ทำภายหลัง

การดูแลเนื้อหา
- article-editorial-metadata.json: ชื่อ SEO คำอธิบาย สรุป FAQ และลิงก์บทความที่เกี่ยวข้อง
- article-optimized-image-manifest.json: ภาพของแต่ละบทความและภาพขนาดมือถือ
- รูปแต่ละบทความไม่ซ้ำกับบทความอื่น แต่หน้าปกและการ์ดของบทความเดียวกันใช้ภาพเดียวกันเพื่อให้จำได้
- ภาพเป็นภาพประกอบจำลอง ไม่มีการอ้างว่าเป็นลูกค้าหรือผลทดสอบสินค้าจริง

มีโค้ด GitHub และ dist/llms.txt แล้ว โดย llms.mjs สร้างข้อมูลสรุปและลิงก์ตาม origin ใน site.config.json การเปิด repository เป็น Public ไม่ได้เปิดเว็บไซต์หรือเปลี่ยนการตั้งค่า indexing โดยอัตโนมัติ
