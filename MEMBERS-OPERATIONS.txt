MAVO Members — สต็อกหมึกของบริษัทลูกค้า
ฉบับในเครื่อง 20 พฤศจิกายน 2569

ขอบเขต
ระบบนี้ติดตามสต็อกที่แต่ละบริษัทลูกค้ามีอยู่ ไม่ใช่คลังสินค้าขายของ MAVO
ยอดมาจากรายการที่สมาชิกหรือทีมบันทึก ไม่ได้อ่านปริมาณหมึกจากเครื่องพิมพ์อัตโนมัติ
หน่วยสินค้าเริ่มต้นตามข้อมูลทะเบียนเป็น “กล่อง” ยังไม่แปลงเป็นจำนวนตลับต่อกล่อง

เริ่มใช้ครั้งแรก
1. เปิด /members.html จากเซิร์ฟเวอร์ในเครื่องเดียวกับเว็บไซต์
2. เมื่อยังไม่มีผู้ใช้ ให้เจ้าของตั้งบัญชีผู้ดูแล MAVO และรหัสผ่านของตนเอง
3. ผู้ดูแลเพิ่มบริษัทลูกค้า แล้วสร้างบัญชีสมาชิกผูกกับบริษัทนั้น
4. บันทึกยอดที่ตรวจนับจริงด้วยรายการรับเข้าและระบุเหตุผล เช่น ยอดเริ่มต้นจากการตรวจนับ
5. ตั้งจุดแจ้งเตือนแต่ละ SKU ตามการใช้งานของบริษัท เมื่อจุดแจ้งเตือนมากกว่า 0 และยอดคงเหลือไม่เกินจุดนั้น ระบบแสดงว่าควรเติม

ทีม MAVO
เลือกบริษัทเพื่อดูยอด รับเข้า ปรับยอดพร้อมเหตุผล ตั้งจุดแจ้งเตือน และติดตามคำขอเติม
ดูประวัติการเคลื่อนไหวเพื่อรู้ว่าใครบันทึกอะไรและเมื่อใด แก้ยอดด้วยรายการปรับยอด ไม่ลบประวัติเดิม
การปรับยอดใช้จำนวนเพิ่มหรือลด เช่น 2 คือเพิ่ม 2 กล่อง ส่วน -1 คือลด 1 กล่อง

สมาชิกบริษัทลูกค้า
เห็นข้อมูลของบริษัทที่บัญชีตนผูกอยู่ บันทึกเบิกใช้ ส่งคำขอเติม และยืนยันรับของที่ทีมระบุว่าส่งแล้ว
การเบิกใช้เกินยอดคงเหลือจะถูกปฏิเสธ
สมาชิกไม่สามารถดูหรือแก้ข้อมูลของบริษัทอื่น และไม่สามารถใช้หน้าที่ผู้ดูแลได้

คำขอเติม
ขอเติม → ทีมตรวจแล้ว → ส่งแล้ว → รับแล้ว
คำขอเติมไม่ใช่คำสั่งซื้ออัตโนมัติ ทีมต้องยืนยันสินค้า ราคา และเงื่อนไขกับลูกค้าก่อนจัดส่ง
ยอดสต็อกบริษัทจะเพิ่มเมื่อยืนยันรับของสำเร็จครั้งแรกเท่านั้น ไม่เพิ่มตอนขอเติมหรือกดส่งแล้ว
สมาชิกยกเลิกคำขอของตนได้ระหว่างที่ยังรอตรวจ ทีมยกเลิกได้ก่อนรับของ
หากทีมยืนยันรับของแทนลูกค้า ต้องใส่เหตุผลหรือหลักฐานอ้างอิง

ข้อมูลและการรัน
ใช้ Node.js 24 ขึ้นไปที่มี node:sqlite
node build.mjs — สร้างหน้าเว็บการตลาด
node server.mjs — รันเว็บและ API สมาชิก โดยรับการเชื่อมต่อเฉพาะ 127.0.0.1
MAVO_PORT กำหนดพอร์ต; MAVO_DB_PATH กำหนดตำแหน่งฐานข้อมูลสำหรับการทดสอบแยก
ฐานจริงเริ่มต้น: private-data/members.sqlite อยู่นอก dist และไม่ถูกเสิร์ฟผ่านเว็บ
รหัสผ่านจัดเก็บเป็นแฮช ไม่ใช้รหัสผ่านเริ่มต้นที่ฝังในระบบ
node backup-members.mjs — สำรอง SQLite แบบสอดคล้องกัน แม้เซิร์ฟเวอร์กำลังทำงาน เก็บใน private-data/backups
ไฟล์สำรองมีข้อมูลสมาชิกและธุรกิจ เก็บในพื้นที่ภายในที่เข้าถึงได้เฉพาะผู้รับผิดชอบ

การส่งมอบ
สมาชิกต้องใช้ server.mjs และ members-api.mjs ควบคู่กับ dist จึงทำงานได้ การเปิดไฟล์ members.html ตรง ๆ หรือฝากเฉพาะไฟล์ static จะไม่ทำให้เข้าสู่ระบบหรือบันทึกสต็อกได้
ไม่แนบฐานข้อมูลจริง private-data หรือข้อมูลทดสอบให้ไฟล์เว็บไซต์สาธารณะ
ยังไม่เปิดลิงก์แชร์ภายนอกตามคำสั่งเจ้าของ หากจะให้ลูกค้านอกเครื่องใช้จริง ต้องจัดระบบโฮสต์ ฐานข้อมูล สำรองข้อมูล และ HTTPS ในงานเผยแพร่ครั้งถัดไป
เมื่อส่งงาน frontend ให้รับ Excel ทะเบียนสินค้าและราคา รวมถึงคู่มือ/เช็กลิสต์แบรนด์จากเจ้าของผ่านช่องทางภายใน เอกสารเหล่านี้ไม่ได้อยู่ใน repository สาธารณะ
